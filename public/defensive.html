Exercise 1: SQL Injection Remediation (Mission 03)

Target: server/vulnerabilities/vulnerabilityEngine.js -> searchProducts()

Root Cause: The application concatenated raw untrusted user input directly into SQL queries. Remediation: Replace dynamic concatenation with parameterized queries, separating SQL code from user data.

❌ VULNERABLE CODE (String Concatenation)
// VULNERABLE: Direct string interpolation
const query = req.query.q;
const sql = `SELECT id, name, category, price
             FROM products
             WHERE name LIKE '%${query}%'
             AND is_confidential = 0`;

return db.rawQuery(sql);
✓ SECURE REMEDIATION (Parameterized Prepared Statement)
// SECURE: Parameterized prepared query
const query = req.query.q;
const sql = `SELECT id, name, category, price
             FROM products
             WHERE (name LIKE ? OR category LIKE ?)
             AND is_confidential = 0`;

const param = `%${query}%`;
return db.all(sql, [param, param]);

Exercise 2: Path Traversal Remediation (Mission 10)

Target: server/vulnerabilities/vulnerabilityEngine.js -> readDocument()

Root Cause: path.join() allowed relative dot-dot-slash (../) sequences to climb outside the documents folder. Remediation: Strip directory components with path.basename() or verify that the resolved canonical path starts with the base directory.

❌ VULNERABLE CODE (Unchecked Relative Path)
// VULNERABLE: Direct path joining allows ../ traversal
const baseDir = '/app/public/documents';
const targetPath = path.join(baseDir, req.query.file);

return fs.readFileSync(targetPath, 'utf8');
✓ SECURE REMEDIATION (Canonical Path Boundary Verification)
// SECURE: Strict canonical path resolution verification
const baseDir = '/app/public/documents';
const safeName = path.basename(req.query.file);
const targetPath = path.resolve(baseDir, safeName);

if (!targetPath.startsWith(baseDir)) {
  throw new Error('Access Denied: Path traversal detected.');
}
return fs.readFileSync(targetPath, 'utf8');
